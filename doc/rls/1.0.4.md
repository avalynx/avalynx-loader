## Release 1.0.4 – Changelog Summary

Security hardening release: the loader text is rendered as plain text, and the
development Docker image actually ships the intended Node.js version.

* **Loader Text Rendered As Plain Text (XSS Hardening)**
  `language.loaderText` is now assigned via `textContent` on a dedicated
  `<span class="visually-hidden">` element instead of being concatenated into
  an `innerHTML` string. Loader texts that carry user-controlled data can no
  longer inject HTML or event handlers into the overlay.
* **Dev Image Installs Node.js 24**
  The `docker/web/Dockerfile` registered the NodeSource repository but never
  installed the `nodejs` package, so containers kept running on the outdated
  Node version bundled with the base image. The install step is in place now;
  tests and builds run on Node 24 as intended.
* **Version Bump Across Assets**
  Updated distributed files, headers, and package metadata to 1.0.4.

**Compatibility**: Backward compatible for plain-text loader texts; texts
containing HTML are escaped now (security fix).
